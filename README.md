# TutorDuel

Website of the paper *Online LLM Personalization from Pairwise Preferences Across Users*
(Romain Puech, Georgy Salakhutdinov, Dimitris Bertsimas, MIT): https://rogy-labs.github.io/tutorduel/

A static page with no build step. Its numbers and figures come from the paper's results. The code and the dataset
will be released with the camera-ready version.
